# Cuaderno de Bitácora — L'Àncora

Manual del equipo de L'Àncora (Roses), publicado como página estática. Sigue la identidad visual compartida de los proyectos `ancoraroses` (navy `#1c3454`, gold `#c8963e`, cream `#F6F1E4`, Georgia/Helvetica, motivos de ancla y cuerda).

Sitio de una sola página (`index.html`, sin dependencias externas) con:
- índice lateral tipo "cuaderno de bitácora", con scroll-spy
- 11 entradas (bienvenida, filosofía, imagen, comunicación, sala, cocina, limpieza, sostenibilidad, normas internas, legalidad, mensaje final)
- 4 anexos (retribución sala/cocina, fichas técnicas, registro de limpieza)

## Publicar en GitHub Pages

1. Crea el repo bajo la organización `ancoraroses`, p. ej. `ancoraroses/manual-equipo`.
2. Sube `index.html` (y este `README.md`) a la rama `main`.
3. En **Settings → Pages**, selecciona la fuente `main` / `/(root)`.
4. Quedará publicado en `https://ancoraroses.github.io/manual-equipo/`.

Si prefieres subirlo desde la web sin usar git: en el repo nuevo, **Add file → Upload files**, arrastra `index.html`, y confirma el commit en `main`.
